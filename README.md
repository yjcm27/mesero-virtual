# Mesero Virtual — Prototipo del cliente

Prototipo de la interfaz del cliente para plazoletas de comidas: escaneo de QR simulado, restaurantes con su propio carrito, alérgenos, pedidos con seguimiento y avisos.

Es una sola página (`index.html`), sin servidor ni instalación. Funciona en Android, iPhone y computador.

> Es un prototipo de demostración: los pedidos no se comparten entre dispositivos y los datos se reinician al recargar.

## Publicar en GitHub Pages

1. Entra a [github.com](https://github.com) e inicia sesión (o crea una cuenta gratuita).
2. Toca **New repository**. Nombre sugerido: `mesero-virtual`. Márcalo como **Public** y crea el repositorio.
3. En el repositorio, toca **Add file → Upload files** y sube `index.html` (y este `README.md`). Luego **Commit changes**.
4. Ve a **Settings → Pages**. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
5. Espera 1 o 2 minutos. El enlace aparece en esa misma pantalla y tiene esta forma:

   `https://TU-USUARIO.github.io/mesero-virtual/`

Envía ese enlace por WhatsApp: se abre en Safari o Chrome sin instalar nada.

## Actualizar el prototipo

Sube un `index.html` nuevo al repositorio (Add file → Upload files). La página se actualiza sola en uno o dos minutos.
